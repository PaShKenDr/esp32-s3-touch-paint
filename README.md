## 📋 Описание

**Touch Paint** — это интерактивное приложение для рисования на ESP32-S3 с матрицей сенсорных кнопок (4×4) и круглым дисплеем GC9A01 (240×240 пикселей).

Приложение позволяет:
- ✅ Рисовать на сетке 4×4, нажимая на сенсорные кнопки (GPIO1-GPIO16)
- ✅ Очищать сетку одной кнопкой (GPIO17)
- ✅ Инвертировать цвета сетки (GPIO18)
- ✅ Видеть результаты в реальном времени на дисплее
- ✅ Получать информацию о состоянии в Serial Monitor

## 🔧 Аппаратное обеспечение

### Требуемые компоненты:
- **Микроконтроллер**: ESP32-S3-R16N16 (16 МБ Flash, 16 МБ PSRAM)
- **Дисплей**: GC9A01 (240×240, круглый TFT-LCD)
- **Тачскрин**: Встроенные ёмкостные сенсоры ESP32-S3
- **Питание**: 3.3В, 500+ мА
- **Подключение**: USB Type-C для программирования

### Распиновка дисплея GC9A01:
```
GC9A01 Pin  →  ESP32-S3 Pin
VCC         →  3.3V
GND         →  GND
CS          →  GPIO10
DC          →  GPIO9
CLK         →  GPIO12
MOSI        →  GPIO11
RST         →  GPIO14
BL          →  GPIO15 (опционально)
```

### Распиновка сенсорных кнопок:
```
Строка 1: GPIO1,  GPIO2,  GPIO3,  GPIO4
Строка 2: GPIO5,  GPIO6,  GPIO7,  GPIO8
Строка 3: GPIO9,  GPIO10, GPIO11, GPIO12
Строка 4: GPIO13, GPIO14, GPIO15, GPIO16

Дополнительные кнопки:
Очистка:      GPIO17
Инвертирование: GPIO18
```

## 📦 Установка и сборка

### Предварительные требования:
- **PlatformIO Core** или **VS Code с расширением PlatformIO**
- **Git** (опционально)

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/PaShKenDr/esp32-s3-touch-paint.git
   cd esp32-s3-touch-paint
   ```

2. **Откройте проект в PlatformIO:**
   ```bash
   pio project init
   ```

3. **Установите библиотеки:**
   ```bash
   pio lib install
   ```

4. **Подключите плату ESP32-S3 через USB Type-C**

5. **Выберите правильный порт (если требуется):**
   ```bash
   pio device list
   ```

6. **Загрузите прошивку:**
   ```bash
   pio run -t upload
   ```

7. **Откройте Serial Monitor для просмотра логов:**
   ```bash
   pio device monitor -b 115200
   ```

## 🎮 Использование

### Основные действия:

1. **Рисование**:
   - Коснитесь одной из 16 сенсорных кнопок на плате
   - Соответствующая ячейка на экране будет подсвечена
   - Отпустите палец — ячейка останется активной
   - Прикоснитесь снова, чтобы деактивировать ячейку

2. **Очистка сетки**:
   - Коснитесь GPIO17 (кнопка CLEAR)
   - Все ячейки вернут на исходное состояние (неактивны)

3. **Инвертирование цветов**:
   - Коснитесь GPIO18 (кнопка INVERT)
   - Все цвета и состояния ячеек инвертируются (активные ← → неактивные)

### Серийный порт (Debug):

В Serial Monitor вы увидите:
```
=== Touch Paint - ESP32-S3 ===
Инициализация дисплея...
Дисплей готов!
Инициализация сенсорных пинов...
Готово! Используйте сенсорные кнопки для рисования.
GPIO1-GPIO16: рисование
GPIO17: очистить
GPIO18: инвертировать

Touch: GPIO1 (Row:0, Col:0) Value:35000
```

## 📊 Конфигурация

Отредактируйте `include/config.h` для изменения:

- **Пороги сенсоров** (`TOUCH_THRESHOLD`)
- **Размеры сетки** (`GRID_COLS`, `GRID_ROWS`)
- **Цвета** (`COLOR_*`)
- **Интервал обновления** (`UPDATE_INTERVAL`)
- **Коэффициенты отладки** (`DEBUG_ENABLED`)

### Пример изменения порога чувствительности:
```cpp
// В include/config.h
#define TOUCH_THRESHOLD     35000  // Меньше = чувствительнее
```

## 🔍 Калибровка сенсоров

Если сенсоры работают неправильно:

1. **Включите режим калибровки** в `include/config.h`:
   ```cpp
   #define CALIBRATION_MODE    1
   ```

2. **Перезагрузитесь и откройте Serial Monitor**

3. **Изучите значения** (не нажимайте на кнопки):
   ```
   GPIO1: 45000
   GPIO2: 46000
   ...
   ```
   Это базовые значения при не нажатых кнопках.

4. **Нажимайте на каждую кнопку** и смотрите как падают значения:
   ```
   GPIO1: 25000 [ACTIVE]
   ```

5. **Отрегулируйте `TOUCH_THRESHOLD`** так, чтобы он был между активным и неактивным состоянием (обычно 35000-40000)

## 🐛 Решение проблем

### Дисплей не инициализируется
- Проверьте подключение SPI пинов
- Убедитесь, что библиотека TFT_eSPI установлена
- Перезагрузите плату (нажмите кнопку EN)

### Сенсоры не работают
- Убедитесь, что пины GPIO1-GPIO18 не используются дисплеем
- Выполните калибровку (см. раздел выше)
- Проверьте значения в Serial Monitor

### Дребезг при срабатывании
- Увеличьте `TOUCH_HYSTERESIS` в config.h
- Используйте стекловолоконную или хлопковую ткань между пальцем и датчиком

### Плата не прошивается
- Убедитесь, что выбран правильный COM порт
- Попробуйте нажать кнопку BOOT при загрузке
- Установите драйверы USB для ESP32-S3
